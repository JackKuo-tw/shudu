# Project: Browser Automation Testing (Playwright)

## Overview
A Playwright-based automation suite to simulate and verify the core conversion behavior of Shudu's web interface.

## Goals
- Automate the verification of the Quill editor integration.
- Ensure the conversion logic (WASM/OpenCC) works correctly in a real browser environment.
- Provide a regression suite for future UI changes.

## Tech Stack
- **Framework:** Playwright
- **Language:** TypeScript
- **Target:** @web/index.html
